# lampa-kinozal: безопасный прототип

Это первый локальный прототип плагина LAMPA для поиска раздач Kinozal.

## Режимы

- `mock` (по умолчанию) — показывает встроенные фиктивные записи. Сеть не используется.
- `proxy` — делает только GET-запросы к явно указанному локальному API. Плагин не знает логин или пароль Kinozal и не отправляет их.

Передача в TorrServe/TorrServer выполняется только после выбора карточки и нажатия «Передать в TorrServer». Адрес обработчика задаётся отдельно. Автоматического добавления раздач, фоновой синхронизации и запросов к приставке нет.

## Файлы

- `plugin.js` — единый внешний JS-файл, который можно загрузить в LAMPA.
- `api-server.js` — небольшой локальный API без зависимостей для проверки режима `proxy`.
- `LAMPA-plugin-docs.md` — сохранённая ссылка на полное официальное руководство по разработке плагинов и список всех разделов.
- `api-contract.md` — минимальный контракт локального read-only прокси и обработчика передачи.
- `mock-results.json` — те же фиктивные данные в JSON для разработки прокси.

## Установка на этапе прототипа

1. Разместить `plugin.js` на локальном HTTP-сервере в домашней сети.
2. В LAMPA добавить URL файла как внешний плагин.
3. В настройках LAMPA открыть раздел «Кинозал — прототип» и оставить режим `mock`.
4. Проверить поиск, открытие карточки и возврат назад с пульта.
5. Только после отдельной проверки прокси переключить режим на `proxy` и указать его URL.

Плагин не устанавливается через ADB и не меняет AT4K, HDMI-CEC или текущие плагины.

## Локальная проверка режима `proxy`

На Windows с установленным Node.js:

```powershell
node .\api-server.js
```

Для загрузки публичных топов Kinozal запустите API так:

```powershell
$env:LAMPA_API_SOURCE = 'public'
node .\api-server.js
```

Если прямой режим получает Cloudflare, используйте браузерный режим:

```powershell
npm install
$env:LAMPA_API_SOURCE = 'browser'
node .\api-server.js
```

Используется единственный профиль `.kinozal-manual-profile` (запускается `kinozal-start.cmd` свёрнутым). При первом запуске
выполните проверку Cloudflare в этом окне вручную. Профиль отдельный: личный
профиль Chrome не используется, а cookies не попадают в репозиторий.

Если автоматизированное окно зацикливает проверку Cloudflare, используйте
отдельное обычное окно Chrome проекта. Личный профиль Chrome к нему не имеет
отношения:

```powershell
$profile = "$PWD\\.kinozal-manual-profile"
Start-Process 'C:\\Program Files\\Google\\Chrome\\Application\\chrome.exe' -ArgumentList @('--remote-debugging-port=9222', "--user-data-dir=$profile", '--new-window', 'https://kinozal.me/top.php')
$env:KINOZAL_CDP_URL = 'http://127.0.0.1:9222'
$env:LAMPA_API_SOURCE = 'browser'
node .\\api-server.js
```

Проверку Cloudflare и вход в этом отдельном профиле выполняет пользователь
вручную. Сервер только читает открытую страницу после этого; личный браузер
и его профиль не используются. Повторные запросы к одному разделу кэшируются
на 2 минуты, а разные запросы идут последовательно с паузой не менее 3 секунд.

После запуска укажите в настройках плагина адрес компьютера в домашней сети, например:

```text
http://192.168.1.10:8787
```

Проверка доступности: `GET /health`. Топ фильмов за неделю: `GET /v1/search?category=movies&period=week&page=1&limit=20`.
Текущий endpoint `/v1/torrents` работает в dry-run режиме: он проверяет magnet и подтверждает запрос, но ещё не отправляет его в настоящий TorrServer.

Публичные страницы Kinozal можно читать без аккаунта. Авторизация потребуется только для скачивания `.torrent` и передачи раздачи в TorrServer; эти секреты не должны попадать в плагин, GitHub или переписку.

## Запуск одной кнопкой (рекомендуется)

На рабочем столе ярлык **«Кинозал»** — это трей-приложение (`kinozal-tray.exe`, собирается из `kinozal-tray.cs` через `kinozal-tray-build.cmd`):

- при запуске **само** поднимает проектный Chrome (порт 9222, профиль `.kinozal-manual-profile`, окно свёрнуто) и API-сервер (порт 8787, режим `browser`, окно не создаётся вовсе);
- иконка в трее показывает статус: «сервер работает / не запущен, Chrome открыт / закрыт»; при изменениях всплывает уведомление;
- меню по правой кнопке: «Запустить всё», «Остановить всё», «Открыть окно Chrome» (развернуть свёрнутый, если понадобилась ручная проверка Cloudflare), «Выход» (выход только убирает иконку, сервисы продолжают работать);
- статусы проверяются каждые 5 секунд (CDP 9222, health 8787).

Резервный путь без трея: `kinozal-start.cmd` / `kinozal-stop.cmd` (внутри — `kinozal-control.ps1`).

## Ограничения

Это UI и контракт для эксперимента. HTML Kinozal, зеркала, CAPTCHA и авторизация намеренно вынесены в локальный прокси: конкретный способ доступа к сайту ещё нужно подтвердить отдельно. Встроенного обхода антибот-защиты нет.
